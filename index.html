    Create and save a Word document in OneDrive

    In this lesson you'll open OneDrive, create a new Word document, give it a name you'll recognize later, and find it again. There is no "Save" button to worry about: Word for the web saves your work automatically.

    Watch the demo

    Press Play to start the demonstration.

    Step by step

    1. Sign in. Go to microsoft365.com and sign in with your UTRGV email and password. Then click the OneDrive icon in the app list on the left.
    2. Create a new file. Click + Create or upload (on some screens it says + Add new), then choose Word document.
    3. Name it right away. Word for the web opens a file called Document or Document1. Click that name at the top of the window and type a name you'll recognize, then press Enter.
    4. Type your content. Watch for the word Saved next to the file name. That means OneDrive saved your work.
    5. Find it again. Go back to OneDrive and click My files. Your document is in the list, with the time you last changed it.

    Name files so you (and your professor) can find them

    "Document1" tells nobody anything. A good filename answers three questions: which class, which assignment, and whose. Use a pattern and stick with it.

    ❌ Hard to find✅ Easy to find
    Document1.docxEDTC3332_ClassNotes_Week9.docx
    paper final FINAL.docxENGL1301_Essay2_Garza.docx
    group thing.docxBIOL1406_Group Project Notes.docx
    Avoid these characters in filenames: / \ : * ? " < > | They can cause upload and sharing errors.

    Lesson two. Share a file, and choose the right permission. When you share, you send one link to the same file. Nobody gets a copy, so everyone always sees the latest version.     Share a file and choose the right permission

    Sharing sends one link to the same file. Nobody gets a copy, so everyone sees the latest version. The most important decision is the permission: can the other person only look, or can they change things?

    Can view vs. Can edit

    👁️ Can view

    They can open and read the file but cannot change it.

    Use it for: turning in a link to your professor, sharing finished notes, sending a study guide to classmates.

    ✏️ Can edit

    They can type, delete, comment, and share the file further.

    Use it for: teammates on a group project, a lab partner, a tutor helping you revise.

    Rule of thumb: give the least access someone needs. If they only need to read it, choose Can view. You can always change it later.

    Step by step

    1. Open the share window. In Word for the web, click Share in the top-right corner. In OneDrive, you can also select the file and click Share.
    2. Add the person. Type their UTRGV name or email in Add a name, group, or email and pick them from the list.
    3. Set the permission. Click the pencil or eye icon next to the name box and choose Can edit or Can view.
    4. Add a short message (optional), like "Here are our notes for the group project."
    5. Click Send. They get an email with the link, and the file shows up under Shared in their OneDrive.

    Turning in a link to a professor? Read this first.

    Why "You need permission" happens: the link only works for the people its settings allow. Before you submit a OneDrive link for an assignment:
    1. Use Copy link and check the setting shown above it (for example, "People in your organization" or "People you choose"). Change it if your professor can't open it.
    2. Choose Can view unless your instructor asks for edit access.
    3. Test the link in a private or incognito browser window before you submit.

    Some sharing options, like "Anyone with the link," may be turned off for university accounts. That's normal. Use the options your account allows.

    Lesson three. Edit, comment, and reopen a shared file. Once a file is shared, your group can work in it at the same time. You'll even see each other's colored cursors as you type. To make an edit, open the shared file from Shared in OneDrive, or from the link in your email. Click where you want to change the text, and type. Your changes save automatically. Comments let you give feedback without changing someone else's writing. Highlight the text, then click Review, and New Comment. Type helpful feedback. To notify a teammate, type the @ sign and their name, like: @Alex, can you add a source here? They'll get an email. Post the comment, and when the issue is fixed, mark it resolved. Later, you can find the updated file under Recent or Shared in OneDrive. And if something gets deleted by mistake, version history lets you restore an older copy.

    Edit, comment, and reopen a shared file

    Once a file is shared, your group can work in it at the same time. You'll see each other's colored cursors as you type. Comments let you give feedback without changing someone else's writing.

    Edit together

    1. Open the shared file. In OneDrive, click Shared on the left, or open the link from your email.
    2. Make your edit. Click where you want to change the text and type. Your changes save automatically, and teammates see them within seconds.

    Leave a comment

    1. Highlight the text you want to comment on.
    2. Click Review → New Comment (or right-click and choose New Comment).
    3. Type helpful feedback. To notify a teammate, type @ and their name, for example "@Alex can you add a source here?" They'll get an email.
    4. Click the send arrow to post it. When the issue is fixed, mark the comment Resolve.

    Find the updated file later

    🕘 Recent

    Files you opened lately, including ones other people own. The fastest place to look.

    👥 Shared

    Files others shared with you, plus files you shared with others.

    ⏪ Version history

    In Word for the web: File → Info → Version History. Lets you see or restore older versions if something gets deleted.

    Good comment vs. not-so-good comment:
    ✅ "@Alex this paragraph needs a citation. Can you add the article we found?"
    ❌ "fix this"

      Summary: Your OneDrive workflow

      You learned one workflow you can reuse for every class: create a file with a clear name, share it with the right permission, and collaborate with edits and comments, all in one file that is always up to date.

      Key takeaways

      • No more attachments. Share one link to one file instead of emailing copies.

      • Comment, don't overwrite. Use comments and @mentions for feedback on someone else's writing.
